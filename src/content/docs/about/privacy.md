Zero to Expert is a static website: a set of pre-built pages with no server-side application behind them. That keeps this policy short.

## What this site does not do

- **No accounts.** There is nothing to sign up for and no login.
- **No ads and no analytics.** The site loads no advertising, analytics, or social-media scripts.
- **No tracking cookies.** The site sets no cookies at all.
- **No third-party fonts or embeds.** Fonts, icons, and styles are served from the site itself, so reading a page does not contact a font or media provider.

## What is stored in your browser

Two small preferences are kept on your own device and are never sent anywhere:

| What | Where | Why |
| --- | --- | --- |
| Your light/dark theme choice | `localStorage`, key `starlight-theme` | So the theme you pick survives a reload. |
| Which sidebar groups are open | `sessionStorage`, key `sl-sidebar-state` | So the sidebar doesn't collapse as you move between pages. Cleared when the tab closes. |

Clearing your browser's site data removes both.

## Search

Search runs inside your browser against an index file that ships with the site. What you type is not sent to a search service.

## What the host collects

The site is hosted on GitHub Pages. GitHub, not this site, operates those servers, and its documentation states that when a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes. See [GitHub's data collection note](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection) and the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). The site owner does not receive those logs.

## Links to other sites

Guides link to official documentation, manufacturer manuals, and other sources. Those sites have their own privacy policies, and this one does not cover them.

## Contacting the site

"Contact Us" opens a new issue on the project's public GitHub repository. Anything you write there is public and is handled under GitHub's terms, not this policy.

## Changes

If the site ever adds analytics, embeds, or anything else that changes the statements above, this page will be updated in the same release.
