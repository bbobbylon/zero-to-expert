This chapter is for anyone who spends the day in an editor and suspects they use a tenth of it. It covers the two I use: **Visual Studio Code** for web, scripts, and this site, and **IntelliJ IDEA** for Java and Spring Boot. The aim is the same in both: keep your hands on the keyboard, let the editor find things for you, and know how to fix it when it breaks.

You need nothing beyond having one of them installed. If you are choosing, Level 0 compares them.

## Roadmap

| Level | Name | You can... |
| --- | --- | --- |
| 0 | Orientation | Name the parts of the window, open anything by typing its name, and pick the right editor for the job. |
| 1 | Beginner | Edit fast: multi-cursor, find and replace across a project, jump to a definition, and format a file. |
| 2 | Intermediate | Run and debug from the editor, use the built-in Git tools, and tune settings without breaking them. |
| 3 | Advanced | Refactor safely, script the editor with tasks and run configurations, and carry your setup to a new machine. |
| 4 | Expert | Build project templates, custom snippets, and keymaps a whole team can share. |
| 5 | Mastery | Write your own extensions and plugins, and explain how the editor indexes and analyses code. |

**Start here:** [Level 0: Orientation](/ides/levels/0-orientation/). The tips pages are the reference you come back to: [VS Code tips and tricks](/ides/concepts/vscode-tips/), [IntelliJ IDEA tips and tricks](/ides/concepts/intellij-tips/), and the [cheat sheet](/ides/cheat-sheet/) for the shortcuts alone.
