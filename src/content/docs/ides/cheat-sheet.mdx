Every shortcut here also appears, with more explanation, on the [VS Code tips](/ides/concepts/vscode-tips/) or [IntelliJ tips](/ides/concepts/intellij-tips/) page — this sheet is the quick look-up version of the two. Shortcuts are each editor's own **default keymap**; if you've customised yours, Find Action (IntelliJ) or the Keyboard Shortcuts editor (VS Code) shows the live binding. As on both source pages, none of these has been pressed on a real keyboard yet — that's the point of the `TODO(test)` notes, and the page stays `draft` until they have been.

## Common

Reach for these dozens of times a day.

<Tabs syncKey="editor">
<TabItem label="VS Code">

### Ask by name, and find files

| Shortcut | What it does |
| --- | --- |
| `Ctrl+Shift+P` (or `F1`) / `⇧⌘P` | Open the Command Palette |
| `Ctrl+P` / `⌘P` | Quick Open: fuzzy-find a file by name |
| `Ctrl+Tab` / `⌃Tab` | Cycle through recently opened editors |
| `Ctrl+G` / `⌃G` | Go to line |

### Multi-cursor

| Shortcut | What it does |
| --- | --- |
| `Alt+Click` / `Option+Click` | Add a cursor where you click |
| `Ctrl+D` / `⌘D` | Select the word at the cursor, then each next occurrence |
| `Ctrl+Shift+L` / `⇧⌘L` | Add a cursor at every occurrence of the selection |
| `Ctrl+Alt+↓` / `Ctrl+Alt+↑` / `⌥⌘↓` / `⌥⌘↑` | Add a cursor on the line below / above |

### Panels

| Shortcut | What it does |
| --- | --- |
| ``Ctrl+` `` / ``⌃` `` | Toggle the integrated terminal |
| `Ctrl+B` / `⌘B` | Toggle the Side Bar |
| `Ctrl+J` / `⌘J` | Toggle the Panel (terminal, problems, output) |
| `Ctrl+K Z` / `⌘K Z` | Toggle Zen Mode (`Esc` `Esc` to leave) |

</TabItem>

### Ask by name, and navigate

| Shortcut (Windows/Linux · macOS) | What it does |

## Rare

:::caution
These are recovery procedures, not single shortcuts — read the situation, and the linked official page, before picking one.
:::

| Editor | Situation | What to do | Source |
| --- | --- | --- | --- |
| VS Code | An extension seems to be causing a slowdown, freeze, or odd completions | Start with `code --disable-extensions` to confirm an extension is the cause. If it is, run **Help: Start Extension Bisect** from the Command Palette to find the culprit by halving the enabled set, instead of toggling extensions one at a time. | [Resolving extension issues with bisect](https://code.visualstudio.com/blogs/2021/02/16/extension-bisect), [Command Line Interface (CLI)](https://code.visualstudio.com/docs/configure/command-line) |
| VS Code | One setting needs to go back to its default | Open the Settings editor, hover the setting, click its gear icon, choose **Reset Setting**. | [User and workspace settings](https://code.visualstudio.com/docs/configure/settings) |
| VS Code | `settings.json` needs a clean slate | Copy the file somewhere first — there is no undo — then delete the entries between the braces. | [User and workspace settings](https://code.visualstudio.com/docs/configure/settings) |
| IntelliJ IDEA | Imports stay red after editing `pom.xml`/`build.gradle` by hand, even after a sync | Try **Reload All Maven Projects** (or Gradle's equivalent full sync) from the Maven/Gradle tool window before assuming something is broken or reinstalling anything. | [Maven projects (sync and reload)](https://www.jetbrains.com/help/idea/delegate-build-and-run-actions-to-maven.html), [Gradle](https://www.jetbrains.com/help/idea/gradle.html) |
| IntelliJ IDEA | The IDE itself is glitching (phantom errors, stuck UI), not one project | Try **Repair IDE** (File → Repair IDE) first — it fixes one project step by step without a restart. Reach for **Invalidate Caches** only after that fails, and read its checkboxes: "Clear file system cache and Local History" also throws away your Local History safety net. | [Repair IDE](https://www.jetbrains.com/help/idea/repair-ide.html), [Invalidate caches](https://www.jetbrains.com/help/idea/invalidate-caches.html) |
| IntelliJ IDEA | You need an old version of a file and there's no commit to restore from | Right-click the file or folder → **Local History → Show History**. It is not a backup: entries are local only and expire after five working days by default. | [Local History](https://www.jetbrains.com/help/idea/local-history.html) |
| IntelliJ IDEA | A keymap got rebound and you want the default back | Settings → Keymap, find the action, right-click → **Reset Shortcuts**. | [Configure keyboard shortcuts](https://www.jetbrains.com/help/idea/configuring-keyboard-shortcuts.html) |
| IntelliJ IDEA | You're about to reset the whole IDE configuration | **Restore Default Settings** backs up the current configuration first, to a dated `-backup` folder under the IDE's settings directory, before resetting. | [Configure project and IDE settings](https://www.jetbrains.com/help/idea/configuring-project-and-ide-settings.html) |
